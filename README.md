These four htmt  files are project files from a climate analysis study of long term temperature data for Ottawa, ON.
Project 1 is a general analysis of 85 years of annual data and for 84 winter season (DJF) data.
Project 2 is a statistical analysis of 85 years of Ottawa's temperature record associated with four atmosheric indices or teleconnections: ENSO,PDO,NAO,AO.
Project 3 is an analysis of 65 years of hourly data to calculate freeze/thaw cycle and investigate changes that have occurred for Ottawa's winter season. (NDJFM).
Project Ottawa references: this fourth file is a list of references used and consulted in the development of the previous research with added material for readers to take a deeper dive into the naterial covered.
